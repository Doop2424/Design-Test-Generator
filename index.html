RCM → 설계평가 템플릿 생성기

RCM 열을 자동 인식하고, 프로세스별 설계평가 파일(RCM + 설계평가 + 통제별 시트 + 증빙)을 만듭니다.
v0.4

1. RCM 파일브라우저 안에서만 처리되고 어디에도 전송되지 않습니다

파일을 끌어놓거나 클릭해 선택.xlsx · .xls · .xlsm
증빙 캡쳐까지 함께 저장됩니다. 브라우저를 닫기 전에 저장하세요.

2. 시트와 행 범위

3. 항목 매핑라벨은 생성될 시트에 그대로 쓰입니다

설계평가 항목RCM 열시트 표기 라벨인식첫 행 값

4. 문구 · 선택항목 설정고치면 <문구 다시 생성>을 눌러 반영

직접 고친 칸은 다시 생성해도 유지됩니다.

5. 설계평가 목록행을 누르면 아래에 해당 통제 시트가 열립니다

6. 통제 시트행 번호·배치가 내보낼 엑셀과 같습니다

캡쳐 이미지를 끌어놓거나 클릭해 선택 · 이 화면에서 Ctrl+V 붙여넣기

7. 엑셀 내보내기프로세스 코드별로 파일이 하나씩 만들어집니다
